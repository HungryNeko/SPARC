Speaker verification calibration

SPARC

Frozen encoders. Calibrated scores.

A small residual on top of a frozen context-affine anchor turns speaker-verification scores into calibrated log-likelihood ratios, using duration, voice-activity and language context.

LLR = anchor + Δ. Because Δ starts at zero, training begins exactly at the anchor.

Anchor first.
Then correct.

SPARC learns only what a strong affine reference misses — and keeps the reference when a correction does not help.

1 · Fit

A frozen anchor.

A source-affine map and a context-affine anchor are fitted on labeled calibration data, then frozen. Every residual starts at zero.

2 · Select

Earned capacity.

Validation chooses among 17 families — the anchor itself, 8 polynomial and 8 small neural residuals — only if Cllr and EER do not get worse.

3 · Deploy

One small file.

A JSON bundle of about 15 KB with at most 289 residual parameters. Prediction checks encoder order and context schema.

Up and running
in a minute.

The synthetic example fits the full procedure, saves a bundle and reloads it. No audio, pretrained weights or datasets needed.

Terminal
pip install -r requirements.txt
python -m examples.synthetic_demo --output-dir outputs/synthetic
Python
from delivery import Plugin, Q_COLUMNS

names = ("encoder_a", "encoder_b")
Plugin.fit(calibration, validation, names, output_path="sparc.json")
llr = Plugin.load("sparc.json").predict(scores, context, names, context_names=Q_COLUMNS)

Five of the eight panel improvements hold under the specified multiplicity adjustment. Cllr is the log-likelihood-ratio cost.
  2. Variance-Gamma is a duration-dependent generative calibrator. It achieves lower cost than SPARC on several other panels and fixed decision thresholds; SPARC is not best on every metric.
